# System Design Learning Plan

A 12-step curriculum to go from working developer (PHP/Go) to software architect.

## Structure

- **[progress.md](progress.md)** — track your status across all 12 steps.
- **[00-overview.md](00-overview.md)** — study method and how to use this plan.
- **01–11** — topic folders, each with a `README.md` (the curriculum) plus 5-6 worked examples in separate files.
- **[12-case-studies/](12-case-studies/)** — 10 real interview-style system design walkthroughs (URL shortener, chat, news feed, payments, etc.).

## How to use

1. Open `progress.md`. Pick the next pending step.
2. Tell Claude **"show me step N"** — Claude reads and displays the step's README + all examples.
3. Read, take notes, mark the step done in `progress.md`.
4. Repeat.
